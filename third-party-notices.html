Datamuse API

  • Purpose: On-demand definitions in the Crossword Solver
  • Provider: Datamuse
  • Service: Datamuse API
  • Definition sources identified by Datamuse: Wiktionary and WordNet 3.0

When a user chooses to look up a matching crossword word, MonkeyTactics requests definition metadata for that word from the Datamuse API. Datamuse asks publicly available applications using its API to acknowledge the service. Definitions are supplied on demand and may be incomplete, unavailable, or drawn from third-party lexical sources subject to their respective terms.
