How to use the Unit Converter

Pick a category (length, weight, temperature, volume, or speed), enter a value in either the From or To box, and choose your units from the dropdowns. The result updates instantly in both directions — type in either field and the other follows.

Use the ⇄ swap button to flip the from/to units, or click Copy bookmarkable link to share an exact conversion.

How conversion works

Each category uses a base unit. Every other unit is defined by a fixed ratio to that base. The converter multiplies your input by the source unit's ratio to get the base value, then divides by the target unit's ratio to produce the answer.

result = value × (fromUnit.toBase ÷ toUnit.toBase)

Temperature is the exception — because Celsius, Fahrenheit, and Kelvin have different zero points, conversions use offset formulas rather than simple ratios. For example, Fahrenheit to Celsius is (F − 32) × 5/9.

Frequently Asked Questions

  • Does this converter support both metric and imperial units?

    Yes. It handles the metric system (metres, kilograms, litres) and the imperial / US customary system (feet, pounds, gallons) across length, weight, temperature, volume, and speed — handy for travel, cooking, engineering, and international trade.

  • Why is temperature conversion different?

    Celsius, Fahrenheit, and Kelvin have different zero points, so conversions use offset formulas rather than simple multiplication. Water freezing at 0°C is 32°F and 273.15 K — same temperature, three different numbers.

  • Can I type into either box?

    Yes. The From and To fields both accept input and update each other live. Whichever field you last typed in becomes the source of the conversion.

  • How precise are the results?

    Results display up to 6 significant digits with trailing zeroes trimmed for a clean readout. The underlying ratios use full IEEE-754 precision.

  • Can I share a specific conversion?

    Yes — click Copy bookmarkable link to create a URL containing the current category, units, and value so someone else can open the same view.

  • Is my data private?

    Yes — all conversions run entirely in your browser using JavaScript. Nothing you type is transmitted to any server. See our Privacy Policy for details.
