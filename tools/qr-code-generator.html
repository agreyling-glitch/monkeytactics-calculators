QR Code Generator FAQ

Which export format should I choose?

PNG is convenient for websites, presentations and common print workflows. SVG stays sharp at any size and is best for vector design software. PDF is useful for print-ready single codes, label sheets, posters, business cards and batch booklets.

Can I create QR codes in bulk?

Yes. Upload a CSV containing up to 250 cleaned QR rows. You can export the selected format, an SVG set, a PDF booklet or mixed PNG and SVG files in one ZIP package.

Can I add a logo without making the QR code unreadable?

Yes, but the logo covers encoded modules. Use safe mode, automatic error-correction adjustment, a contrasting logo background and the live reliability score. Always scan-test the final artwork at its intended printed size.

Where are saved projects and uploaded files stored?

Project data, imported CSV text and embedded logo data are stored locally in your browser. Export a project JSON file if you need a portable backup or want to move it to another browser.

Does a QR code expire?

The QR image itself does not expire. A QR code that contains a direct URL continues to work while that destination remains available. MonkeyTactics does not add a redirect or subscription between the QR code and your destination.
