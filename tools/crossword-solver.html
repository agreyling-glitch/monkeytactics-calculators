    02 / Narrow the possibilities

    How to Use the Crossword Solver

    1. Choose a dictionary: select ENABLE for a broad public-domain list geared toward North American word games, SOWPODS for international British and North American vocabulary, or Both for the widest combined results with duplicates removed. Hover over or focus an option for a short explanation.
    2. Enter the crossword clue as written. Straight definition clues work best; cryptic wordplay is not interpreted.
    3. Add the answer pattern from your grid. Keep known letters in position and use ? for each unknown square.
    4. If you only know part of the answer, use * for a flexible number of letters or set an exact Word Length.
    5. Use Starts With, Ends With, Must Include, or Exclude Letters only when crossing answers support those restrictions.
    6. Compare the highest-ranked definitions with the clue's meaning, tense, plurality, and abbreviation signals.

    03 / Ranking

    How Clue Search Ranks Answers

    The browser compares meaningful clue words with an indexed set of WordNet definitions. Exact phrases and multiple matching clue terms rank higher. Known pattern letters, exact answer length, dictionary membership, and dataset quality then refine the order.

    Results are ranked possibilities, not probabilities. “Best match” means the strongest result in the current filtered set; always confirm it against the puzzle's crossings and clue style.

    Data and privacy

    Private, Browser-Based Crossword Search

    The clue index contains more than 94,000 automatically filtered records derived from Princeton WordNet 3.0. Answer validation uses the ENABLE and SOWPODS word lists. Data loads in compressed pieces only when needed.

    Your clue, pattern, and filters remain on your device. Selecting an answer for the optional dictionary popup sends only that answer word to Datamuse. See data sources and licensing.

    04 / Common questions

    Crossword Solver FAQ

    Can I search using only a crossword clue?

    Yes. Enter the clue without an answer pattern to search and rank matching WordNet definitions. Add the answer length when you know the number of squares.

    How do I combine a clue with crossing letters?

    Enter the clue, then type the known letters in their grid positions and use a question mark for each unknown square. The solver ranks clue matches that also fit the pattern.

    Can I search by letter pattern only?

    Yes. Leave the clue blank and enter a pattern. The solver searches the selected ENABLE or SOWPODS dictionary without loading clue data.

    What do question marks and asterisks mean?

    A question mark matches exactly one unknown letter. An asterisk matches zero or more letters when the answer length is uncertain.

    Where do the crossword clues come from?

    Clue search uses an automatically filtered and transformed dataset derived from Princeton WordNet 3.0. Pattern-only answers come from ENABLE and SOWPODS word lists.

    Are crossword searches private?

    Yes. Clues, patterns, filters, and ranking stay in your browser. If you open an optional definition lookup, only the selected answer word is sent to Datamuse.
