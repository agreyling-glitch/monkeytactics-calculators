    02 / Narrow the possibilities

    How to Use the Crossword Solver

    1. Choose a dictionary: select ENABLE for a broad public-domain list geared toward North American word games, SOWPODS for international British and North American vocabulary, or Both for the widest combined results with duplicates removed. Hover over or focus an option for a short explanation.
    2. Enter the crossword clue as written. Straight definition clues work best; cryptic wordplay is not interpreted.
    3. Add the answer pattern from your grid. Keep known letters in position and use ? for each unknown square.
    4. If you only know part of the answer, use * for a flexible number of letters or set an exact Word Length.
    5. Use Starts With, Ends With, Must Include, or Exclude Letters only when crossing answers support those restrictions.
    6. Select Reset inside Filters to clear only the secondary filters without losing the clue, pattern, dictionary, Pick List, or current results.
    7. Pause the pointer over an answer to preview its definition, or select it with a click or keyboard. Compare the highest-ranked definitions with the clue's meaning, tense, plurality, and abbreviation signals.
    8. Select Add to Pick List in the definition window to save the answer with its clue, pattern, match details, grid position, and private crossing notes.
    9. Assign the same Grid Position to group alternative answers together. After a position is defined, select it from the suggestions on another candidate instead of retyping it. Use the Pick List actions menu to export the complete shortlist or import it with Merge or Replace.
    10. Use Insert to restore and rerun a saved candidate search, or Share to create a compact link, formatted clipboard summary, and QR code.

    03 / Ranking

    How WordNet Crossword Clue Ranking Works

    The browser compares meaningful clue words with indexed WordNet definitions, synonyms, and graph relationships such as broader, narrower, and similar concepts. Literal terms and exact phrases rank higher than related meanings. Known pattern letters, exact answer length, dictionary membership, and dataset quality then refine the order.

    Results are ranked possibilities, not probabilities. “Best match” means the strongest result in the current filtered set; always confirm it against the puzzle's crossings and clue style.

    Save and continue

    Build a Crossword Candidate Pick List

    Save promising crossword answers with their clue, answer pattern, matched definition, explainable match strength, dictionary membership, grid position, notes, and timestamp. Candidates sharing a Grid Position are organized into a collapsible group, while answers without a position remain under Unassigned. Grid Position fields suggest positions already used in the Pick List, while still allowing new positions.

    Select Insert on any pick to restore its clue, pattern, inferred length, and dictionary and immediately rerun the answer search. This makes it easier to revisit alternatives as crossing letters change.

    Share a candidate

    Share Crossword Answers by Link or QR Code

    Each saved pick can generate a compact Crossword Solver URL and a scannable QR code. The formatted clipboard summary includes the answer, clue, pattern, matched definition, ranking details, dictionary, timestamp, and direct solver link.

    Opening a shared link fills the clue and pattern controls, infers the answer length, selects the dictionary, runs the search, and adds the candidate to the recipient's browser-local Pick List.

    Data and privacy

    Private, Browser-Based Crossword Search

    The clue index contains more than 129,000 automatically filtered records derived from Princeton WordNet 3.0, including over 34,000 multi-word answers. Phrase spacing is shown in results while patterns and answer length count letters as crossword grid cells. Semantic graph relationships—including broader, narrower, and similar concepts—help find answers beyond exact clue words. Answer validation uses the ENABLE and SOWPODS word lists. Data loads in compressed pieces only when needed.

    Your clue, pattern, filters, Pick List, grid positions, notes, and exported JSON files remain under your control. A share link contains only the answer, clue, pattern, and dictionary selection. Selecting a single-word answer for the optional definition popup sends only that answer to Datamuse; repeated lookups reuse a temporary page-session cache. See data sources and licensing.

    Move or back up a shortlist

    Export and Import a Crossword Pick List

    Open the Pick List actions menu to export every saved candidate, clue, pattern, definition, semantic score, Grid Position, and note as a versioned JSON file. Import it later or move it to another browser without re-entering the puzzle.

    Choose Merge to add new candidates while skipping duplicates, or Replace to overwrite the current Pick List after confirmation. Imported files are validated before any candidate is saved.

    04 / Common questions

    Crossword Solver FAQ

    Can I search using only a crossword clue?

    Yes. Enter the clue without an answer pattern to search and rank matching WordNet definitions. Add the answer length when you know the number of squares.

    Can the solver understand synonyms?

    Yes. When a clue does not directly match words in a WordNet definition, the solver can retrieve answers through closely related WordNet synonyms. Literal clue words and exact phrases receive more weight, so related meanings broaden the results without replacing stronger direct matches.

    Does the crossword solver support multi-word answers?

    Yes. The WordNet clue dataset includes more than 34,000 multi-word answers. Results preserve spaces for readability while answer length and letter patterns count only crossword grid letters.

    How does WordNet graph similarity rank crossword answers?

    The solver compares clue words with WordNet definitions, synonyms, and semantic relationships such as broader, narrower, and similar concepts. The result window explains the score contributions so you can distinguish direct clue matches from related meanings.

    What does the crossword Pick List save?

    Each pick stores the answer, clue, pattern, matched WordNet definition, numeric match strength, clue-word count, dictionary membership, grid position, notes, and timestamp. Pick List data remains in this browser unless you export it.

    Can I export or import a crossword Pick List?

    Yes. Open the Pick List actions menu to export every candidate and its solving context as versioned JSON. Import can merge candidates with the current list or replace it after confirmation.

    How do I reopen a saved crossword search?

    Select Insert beside a Pick List candidate. The solver restores its clue, answer pattern, inferred length, and dictionary, clears unrelated secondary filters, and runs the search again.

    Can I reset only the crossword filters?

    Yes. The Reset button inside Filters clears length, sorting, letter-pool, starts-with, ends-with, must-include, and excluded-letter settings without clearing the clue, pattern, dictionary, Pick List, or current results.

    Can I share a crossword pick?

    Yes. Select Share beside a saved pick to create a compact deep link, formatted copyable summary, and URL QR code. The link includes only the answer, clue, pattern, and dictionary. Opening it restores the search controls, runs the search, and adds the candidate to the recipient's browser-local Pick List.

    How do I combine a clue with crossing letters?

    Enter the clue, then type the known letters in their grid positions and use a question mark for each unknown square. The solver ranks clue matches that also fit the pattern.

    Can I search by letter pattern only?

    Yes. Leave the clue blank and enter a pattern. The solver searches the selected ENABLE or SOWPODS dictionary without loading clue data.

    What do question marks and asterisks mean?

    A question mark matches exactly one unknown letter. An asterisk matches zero or more letters when the answer length is uncertain.

    Where do the crossword clues come from?

    Clue search uses an automatically filtered and transformed dataset derived from Princeton WordNet 3.0. Pattern-only answers come from ENABLE and SOWPODS word lists.

    Are crossword searches private?

    Yes. Clues, patterns, filters, and ranking stay in your browser. If you open an optional definition lookup, only the selected answer word is sent to Datamuse.

    What does Cached this session mean?

    It means that answer's Datamuse definition was already requested during the current page session and the saved response was reused. The temporary definition cache clears when the page is reloaded.
