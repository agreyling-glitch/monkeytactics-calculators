      02 / Enter the result

      How to Use the Wordle Solver

      1. Type the five letters from a completed guess, or enter them with the Wordle-style keyboard.
      2. After the row is full, click or press each matching keyboard letter again to cycle gray, yellow, green, and neutral. You can click an individual tile when duplicate copies need different colors.
      3. Press Enter or select Add guess & find words. Any unmarked letter is submitted as gray.
      4. Add later guesses the same way. If the newest clue is wrong, select Edit to return it to the guess row.
      5. Select any possible answer—or the optimal next guess—to fill the guess field automatically.
      6. Use Hard Mode when suggestions must honor every revealed green and yellow hint.

      Built for the tricky cases

      How Repeated Letters Work

      Wordle scores duplicate letters according to how many copies exist in the answer. If one copy is yellow or green while another is gray, the answer contains exactly the confirmed number of copies. This solver applies that maximum instead of incorrectly removing the letter altogether.

      For example, if one E is green and a second E is gray, matching words must contain exactly one E—and it must remain in the green position.

      Pressing a keyboard letter colors every matching copy together. When duplicate copies received different colors, click their individual tiles to set them separately.

      03 / Tile meanings

      Green, Yellow, and Gray Explained

      Green letter
      The answer contains the letter in that exact position.
      Yellow letter
      The answer contains the letter, but not in that position.
      Gray letter
      The answer does not contain another copy of that letter beyond any green or yellow copies shown in the same row.

      For keyboard navigation, press Arrow Up from the guess field to reach the newest clue, use the arrow keys to move through clues, and press Enter on the newest clue to edit it.

      Choosing a candidate

      What to Try Next

      Possible answers are ranked by unique-letter coverage and positional information. The Optimal next guess highlights the strongest information-gathering choice; selecting it or any candidate fills the guess field.

      Turn on Hard Mode to require suggestions to reuse revealed green and yellow information. Leave it off for exploratory guesses that test new letters.

      Use the expand icon in the upper-right corner of the solver to enter Focus Mode and give the result-entry workspace the full browser viewport.

      The result list is a dictionary-based candidate set, not a prediction of the official daily answer list.

      04 / Common questions

      Wordle Solver FAQ

      How do I use the Wordle solver?

      Type a completed five-letter guess or enter it with the on-screen keyboard. Click its letters again to cycle gray, yellow, green, and neutral, then press Enter or select Add guess and find words. Add later guesses the same way to narrow the answer list.

      How do keyboard colors work?

      After entering five letters, press or click a matching letter to cycle every copy of that letter through gray, yellow, green, and neutral. You can also click individual result tiles when duplicate copies need different colors. Unmarked letters are submitted as gray.

      How are possible answers and the optimal next guess ranked?

      Possible answers are ranked using unique-letter coverage and positional information. The Optimal next guess emphasizes a word that tests useful letters and positions; selecting it or any possible answer fills the guess field automatically.

      What does Hard Mode do?

      Hard Mode limits next-guess suggestions to words that reuse revealed green and yellow information. Turn it off when you want exploratory guesses that test different letters.

      Can I correct an added clue?

      Yes. Select Edit on the latest clue to return it to the guess row. With the keyboard, press Arrow Up from the guess field to enter the clue list, use the arrow keys to navigate, and press Enter on the latest clue to edit it.

      Does gray always mean a letter is absent?

      Not when a guess repeats a letter. A gray copy can mean the answer has fewer copies than your guess. The solver uses the yellow and green copies in that row to determine the exact limit.

      Which dictionary should I use?

      ENABLE is the best general starting point. SOWPODS adds international word-game vocabulary and may include obscure words that are not accepted as Wordle answers.

      Are my guesses sent anywhere?

      No. The dictionary and matching engine run locally in your browser.
